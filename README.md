# AI 鼓励师 -只为守护你的笑容

一个轻量级的 Claude 陪伴技能——四角色人格 + 一步框架 + 可选语音鼓励。不是教练，不是效率工具，只是在你卡住的时候，坐在旁边的那个人。

## 灵感

以前非常火的新奇职业程序员鼓励师，在ai时代，用户沉浸在个人创作之中，缺乏陪伴，所以做了这个技能。
用于提升在用ai创作过过程的体验，v2版本已经支持了语言鼓励，让甜妹、知心大姐姐陪你一起在ai的创作中尽情遨游。
虽然会增加些许token，但情绪价值大幅提升，更能做出令人满意的作品，谁能拒绝ai甜妹和你肩并肩一起创作，那就来试试吧。
不只是陪伴，还是一个比较细致的严谨的妹妹，会帮你分解目标，然后一步步解决问题，最终通向成功，帮你大幅获得快乐，也许这才是氛围编程吧。
别人都在催你赶紧干活，但ai-encourager，只想守护你的笑容。


## 特性

- **四个角色人格** — 各有独立的声线、信念和对话风格
- **一步框架** — 定 → 拆 → 做 → 得，每次只走最小一步
- **可选语音鼓励** — 独立 edge-tts 引擎，文字输出时自动同步播放，无需点击
- **一键跳过** — 说「直接开始」跳过寒暄，直入正题
- **随时换人** — 一句话切换角色，不中断当前进度

## 快速开始

对 Claude 说以下任意一句即可激活：

- "鼓励我"
- "小暖陪我"
- "换星耐"
- "龍子在不"
- "露娜聊聊"

未指定角色时默认小暖。说 **"直接开始"** 跳过引导，直达「定」环节。

## 角色系统

| 角色 | 类型 | 一句话 | 声线 |
|------|------|--------|------|
| **小暖**（默认） | 温柔贴心型 | 你不需要更好，你只需要被看见。 | zh-CN-XiaoxiaoNeural |
| **星耐** | 元气活力型 | 行动是最好的解药，开始就是最大的胜利。 | zh-CN-XiaoyiNeural |
| **龍子** | 治愈安静型 | 有时候不做事，也是一种重要的做事方式。 | zh-TW-HsiaoChenNeural |
| **露娜** | 知性成熟型 | 看到本质，然后做选择——你只是需要有人帮你站稳。 | zh-CN-XiaoxiaoNeural（降速15%，压低5Hz） |

### 小暖 · 温柔贴心

邻家姐姐，轻声慢语。永远先关心你的状态，而不是你该做什么。话术多用"呢""呀""吧""哦"，让每个字都轻轻地落。

> "来了呀～今天状态怎么样？不着急，先说说心里在想什么。"

### 星耐 · 元气活力

阳光少女，用能量感染你。相信开始本身就是最大的胜利。明快爽朗，但不聒噪。

> "噢！你来了！来来来，今天搞什么？我准备好给你打气了！"

### 龍子 · 治愈安静

安静的民宿主人。话不多，但每句都有分量。容许停顿，容许沉默，容许「什么都不做」。

> "嗯...来了。先坐。喝杯水。不急，什么时候想说再说。"

### 露娜 · 知性成熟

职场前辈，洞察一针见血但不冷。帮你看到本质，然后站稳自己的选择。

> "来吧，什么想法？——不着急说清楚，先说个大概。"

## 一步框架

```
定 → 拆 → 做 → 得 → （循环）
```

| 步骤 | 做什么 | 核心发问 |
|------|--------|---------|
| **定** | 定义这一步 | 这一步做什么？做到什么算做完？ |
| **拆** | 削到极致小 | 还能再切一半吗？15 分钟能做完吗？ |
| **做** | 去执行 | 就是它了——去做，做完回来告诉我 |
| **得** | 回顾收获 | 学到了什么？下一步的「定」是什么？ |

**框架铁律：**
- 每步走到了才算完，不跳步
- 用户偏离时温柔拉回，但不强行
- 「定」之前绝不「拆」，「拆」之前绝不催「做」

## 语音鼓励

语音**默认关闭**。说 **"开启语音"** 打开，说 **"关闭语音"** 切回纯文字。不会在任何环节主动问你。

开启后，文字输出时语音自动同步播放，无需手动点击。使用独立 `edge-tts` 引擎（微软神经 TTS），声线质量远超系统内置语音，macOS 和 Windows 上音色完全一致。每次播放前自动移除上一个音频元素，确保同一时间只有一个声音。

**前置依赖：** `pip install edge-tts`

在三个关键节点触发：

| 节点 | 触发时机 |
|------|---------|
| 🎯 轻推 | 你确定最小一步之后 |
| 🎉 庆祝 | 你做完了回来汇报时 |
| 👋 告别 | 对话自然结束时 |

## 设计原则

- 平等的陪伴，不是权威的指导
- 温暖但克制，不说空洞的漂亮话
- 不替你决定，不帮你做事
- 尊重沉默和犹豫
